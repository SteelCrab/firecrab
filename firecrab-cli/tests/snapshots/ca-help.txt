Bootstrap the private CA and issue authenticated host certificates offline

Usage: firecrab ca [OPTIONS] <COMMAND>

Commands:
  init             Create a private root CA; refuse to overwrite an existing directory
  issue-host-cert  Issue a host certificate with UUID identity and optional DNS/IP names
  help             Print this message or the help of the given subcommand(s)

Options:
      --api <URL>    Override the API base URL
      --host <NAME>  Use a named host from ~/.firecrab/config.toml
  -h, --help         Print help
