# PIPE database screenshots

Captured on 2026-10-22 after merging the latest `main` dashboard design.
All captures use English UI text and disposable API fixtures. The complete
`npm run test:pipe --prefix firecrab-e2e` run passed 114 cases, including 22
database cases. The 22 database cases also passed separately. Three layout and
preview cases were repeated after the final spacing adjustments.

| File | Scenario |
| --- | --- |
| `database-preview-desktop.png` | Desktop table preview, NULL values and pagination |
| `database-preview-mobile.png` | Saved connection and read-only preview at a 390×844 viewport |
| `database-form-mobile.png` | Compact RDS connection form with optional TLS settings collapsed at a 390×844 viewport |

The captures contain no database passwords, CA certificates or live credentials.

Real PostgreSQL 17 and MySQL 8.4 desktop/mobile screenshots are generated by the
`pipe-databases` CI job and retained in its `pipe-databases-qa` artifact. Those
checks use real API/database connections with English UI text and a non-ASCII
text fixture. See the [QA guide](../../../public-docs/development/pipe-databases-qa.md).

## Previous real database validation

Real database QA was not repeated for this UI update. The live browser test
uses the new TLS disclosure and connection action menu; CI runs it against the
disposable databases.

[CI revision `82ce9e3`](https://github.com/SteelCrab/firecrab/actions/runs/39575826968)
passed all 18 QA groups with PostgreSQL 17.11 and MySQL 8.4.11. This includes
four real browser cases: desktop and mobile for each engine. The checks cover
TLS certificate verification, restart persistence, credential redaction and
source data preservation.

The [QA artifact](https://github.com/SteelCrab/firecrab/actions/runs/39575826968/artifacts/12333788029)
contains the report, four real database screenshots and the LCOV report. CI
retains this artifact for seven days.
