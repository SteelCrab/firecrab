# Terminal dependencies

The console uses `ghostty-web` 0.4.0-next.20.g1858a59 by Coder, licensed under MIT.
Its WebAssembly terminal core is derived from Ghostty by Mitchell Hashimoto
and the Ghostty contributors, also licensed under MIT.

Sources:

- https://github.com/coder/ghostty-web
- https://github.com/ghostty-org/ghostty

Firecrab build modifications: externalize the identical WASM binary and defer
Canvas sizing/rendering during terminal resize to the existing animation loop.
The renderer also tracks browser pixel-ratio changes and skips wide-cell
continuations in copied selections. The original package stays unchanged;
the Vite build checks every patch.
